# Korean Learning Context

This context defines how the tutor describes and tracks the learner's familiarity with Korean language items.

## Learning-state language

**Language item**:
A Korean word, expression, or grammar structure whose familiarity is tracked.
_Avoid_: Vocabulary item when referring to grammar structures as well.

**Unseen**:
A language item the learner has not encountered before. It is a candidate for introduction and becomes Learning when the learner chooses to study it.
_Avoid_: Unknown as a separate state; it is only a learner-facing synonym for Unseen.

**Learning**:
A language item the learner has encountered recently or explicitly wants to keep practicing with more examples and retrieval practice.
_Avoid_: New; a Learning item has already been encountered.

**Seen**:
A language item the learner recognizes and does not want proactively recommended. It can still be used or corrected naturally, and this state does not claim perfect mastery; the learner can move it back to Learning by asking for review.
_Avoid_: Mastered, known; those imply a stronger level of command than this state requires.

**Learning pile**:
The set of language items currently in Learning state.
_Avoid_: Vocabulary list when grammar structures are included.

**Sentence mine**:
A short, source-linked Korean example selected for natural everyday usage and teaching value.
_Avoid_: Full transcript or article excerpt.

**Sentence digest**:
A compact set of sentence mines prepared for one day's lesson or review.
_Avoid_: An unfiltered content feed.
